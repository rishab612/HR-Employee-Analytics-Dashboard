# 📊 HR Employee Analytics Dashboard

An end-to-end HR Analytics project built using **Python, Excel, MySQL, and Power BI** to analyze employee workforce data, attrition, salary, performance, satisfaction, and workforce trends.

---

## 📌 Project Overview

The HR Employee Analytics Dashboard provides an interactive view of a company's workforce and helps analyze:

- Employee demographics
- Workforce distribution
- Employee attrition
- Salary and compensation
- Job roles and departments
- Employee performance
- Job satisfaction
- Work-life balance
- Overtime
- Employee tenure
- Training
- Hiring trends

The project uses a complete data analytics workflow:

**Python → Excel → MySQL → Power BI → Business Insights**

---

# 🎯 Project Objectives

The main objectives of this project are:

1. Analyze the overall employee workforce.
2. Calculate employee attrition and attrition rate.
3. Identify attrition patterns across departments and job roles.
4. Analyze salary distribution.
5. Study employee performance.
6. Analyze employee satisfaction.
7. Examine overtime and work-life balance.
8. Analyze employee tenure.
9. Create an interactive Power BI dashboard.
10. Generate business insights from HR data.
